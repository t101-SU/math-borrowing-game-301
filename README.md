# 🍬 魔法糖果工坊 - 國小三年級四位數減法借位互動遊戲

這是一款專為國小三年級學生設計的數學互動教學網頁遊戲。遊戲針對孩子在四位數直式減法中最常卡關的「借位（退位）」、「連續借位」以及「跨零借位」痛點，以「具象化教具（糖果拆箱）」結合「數學標準直式算式」進行雙向動態連動，幫助孩子建立清晰直觀的數感概念。

---

## 🌟 核心特色與教學設計

1. **具象化十進位教具（左側糖果庫存台）**：
   - **千位**：📦 1000 顆裝大貨箱
   - **百位**：🛍️ 100 顆裝分享包
   - **十位**：🏺 10 顆裝糖果罐
   - **個位**：🍬 單顆星星糖
   - 當孩子點擊「向左借位」時，左側較大的糖果包裝會「砰！」一聲拆開，飛入右側變成 10 個較小的包裝，生動展示「借 1 當 10」的真正含義。

2. **標準小學直式算式連動（右側計算台）**：
   - 同步呈現學校課本標準劃記：借位時自動產生斜線劃掉被借的位數，上方浮現減 1 後的數字，並於目標位數標註 `+10`。
   - 解決學生「忘記已經借過」或「借了忘記加 10」的常見筆誤。

3. **破解跨零借位（大魔王關）**：
   - 面對如 $4005 - 1837$ 或 $5000 - 2345$ 這類隔壁位數是 0 的題目，遊戲會引導孩子理解：
     - 個位向十位借 ➔ 十位是 0 沒有糖果！
     - 十位向百位借 ➔ 百位也是 0！
     - 百位向千位借 ➔ 千位借出 1 箱變 10 包 ➔ 百位再借出 1 包變 10 罐（百位剩 9 包）➔ 十位再借出 1 罐變 10 顆（十位剩 9 罐）！
     - 直觀解開孩子心中「為什麼中間的 0 借完會變成 9」的千古謎題。

4. **三大遊玩與學習模式**：
   - 🌟 **示範教學模式**：經典範例逐步導引，手把手教學。
   - 🏆 **闖關冒險模式**：
     - **第 1 關（暖身）**：單次借位
     - **第 2 關（挑戰）**：連續借位
     - **第 3 關（魔王關）**：跨零借位
   - ✏️ **自由出題模式**：支援老師、家長自訂四位數算式，或一鍵隨機生成題目。

5. **可愛活潑兒童介面**：
   - 糖果精靈「泡泡」對話框即時提示，答錯溫和引導不挫折。
   - 純瀏覽器原生 Web Audio API 合成音效（免除外部音檔遺失問題）。
   - 過關撒花慶祝動畫與獎勵彈窗。
   - 支援螢幕觸控大鍵盤與實體鍵盤（0-9、空白鍵借位）。
